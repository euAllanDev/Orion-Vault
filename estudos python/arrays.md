# Arrays em Python

Em Python, estruturas parecidas com arrays sao usadas para guardar varios valores em uma unica variavel. O tipo mais comum e a lista, que permite armazenar elementos diferentes, acessar por indice, adicionar, remover e percorrer itens com facilidade.

Quando voce precisa de dados mais homogeneos e desempenho melhor, pode usar o modulo `array` ou bibliotecas como `numpy`.
